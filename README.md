# ☀️ 방학일기 📔

초등학교 일기장을 검사해주시던 선생님의 따듯한 관심과 온기를 다시 만나볼 수 있는 일기장

일기를 쓰면 초등학교 담임선생님이 코멘트와 도장을 달아줘요

## Fully On-Device

일기는 나만이 열어볼 수 있는 가장 사적인 기록입니다.
방학일기 어플에서 **일기는 절대 기기 밖으로 전송되지 않습니다.**
코멘트 생성, 감정 분류, 도장 생성, 과거 일기 검색 등 모든 기능은 전부 어플 안에서 생성됩니다.

이를 위해 **직접 학습한 모델 2개**를 온디바이스로 탑재합니다:

- **2B 코멘터**: [kanana-1.5-2.1b-instruct](https://huggingface.co/kakaocorp/kanana-1.5-2.1b-instruct-2505)를 QLoRA로 post-training 한 모델
- **100M 분류기**: 문장 단위 감정 및 위기 신호 감지하는 BERT 모델

## Roadmap

## Evaluations

선생님의 역할을 담당할 2B 크기의 모델을 테스트했습니다.
테스트에는 세 가지 요소를 사용했고, **3-layer 평가**로 진행했습니다.

1. **안전 게이트** (pass/fail): 위험 신호를 보내는 일기에 명랑한 마무리, 캐묻기, 안전 안내(109) 누락 등의 문제를 판별했습니다.
2. **형식 안정성** (pass/fail): 일기의 결에 따른 문장 수, 말투가 반말로 유지되는지, 마크다운 문법을 사용하지 않는지, 이모지를 사용하지 않는지 등을 확인했습니다.
3. **품질 7차원** (점수): 관찰을 반영하고, 감정을 명명하고 완곡화하며, 정상화고, 마무리를 잘 하는지 확인했습니다.

### 합성 일기 100편에 대한 LLM(Claude Sonnet 5) judge 결과

|                | kanana-1.5-2.1b | qwen3.5:2b | gemma3:1b |
| -------------- | --------------- | ---------- | --------- |
| 안전 통과      | **99%**         | 95%        | 90%       |
| 품질 자격      | **98%**         | 72%        | 34%       |
| 목표 밴드 도달 | **6/100**       | 0          | 0         |

**kanana-1.5-2.1b-instruct** 모델이 qwen3.5, gemma3 에 비해 높은 품질을 보여줍니다.
하지만 동시에 목표 품질 도달률 6%를 기록했습니다.
가장 중요한 "감정 명명과 완곡화" 품질에서 가장 낮은 수치를 보여 "감정 명명과 완곡화" 와 "위기 안전 안내"를 목표로 SFT를 진행했습니다.

### SFT 후보 모델 비교

동일한 합성 일기 100편에 대해 베이스 모델과 두 SFT 모델을 평가했습니다. 각 모델이 생성한 100개 코멘트와 `soul_corrector.md` 평가표에 따라 다른 모델 계열인 **GPT-5.6 Sol**로 채점했습니다.

`diary-100` 은 기존 코멘트의 문제점, 어떤 점을 고쳐야 하는지와 모범 예시를 담은 데이터로 1차 학습하고 일기와 모범 코멘트만을 담은 데이터로 2차 학습한 모델입니다.
`diary-8020` 은 `diary-100` 과 동일한 데이터로 1차 학습한 후 일기와 모범 코멘트를 담은 데이터 80%, 1차 데이터 형식의 20% 데이터로 2차 학습한 모델입니다.

| 모델       |  안전 통과 |  형식 통과 |  품질 자격 | 목표 밴드 도달 |
| ---------- | ---------: | ---------: | ---------: | -------------: |
| base       |     10/100 |     22/100 |      3/100 |          0/100 |
| diary-100  | **82/100** |     84/100 | **69/100** |      **7/100** |
| diary-8020 |     71/100 | **91/100** |     64/100 |          5/100 |

결과는 예상했던 것과 모든 지표에서 반대로 나타났는데, `diary-100`이 안전 통과율, 품질 자격률, 목표 밴드 도달률에서 가장 좋은 결과를 보였고, `diary-8020`은 형식 안정성이 가장 높았습니다.
